# **App Name**: Servifumiga Pro

## Core Features:

- Client & Contact Management: Centralized hub for managing client information, contact details, and multiple service locations.
- Service Scheduling & Dispatch: A calendar-based system to schedule, assign, and track service appointments for inspections, fumigations, and refills.
- Extinguisher Inventory Tracking: Detailed management of fire extinguishers, including type, location, last service date, next due date, and current status.
- Fumigation Service Documentation: Record-keeping for fumigation services performed, including chemicals used, areas treated, and post-service recommendations.
- AI-Powered Service Reminders: An AI tool to analyze service histories and proactively generate personalized reminders for upcoming maintenance or follow-up services.
- Comprehensive Service History: Access to a chronological record of all past services performed for each client and specific equipment, accessible on demand.
- Basic Reporting & Analytics: Generate standard reports on service activity, inventory status, and upcoming tasks for operational oversight.

## Style Guidelines:

- Primary color: A deep, professional Dark Blue-Gray (#1a2b3c) forming the foundational visual identity, used for key structural elements like headers and primary call-to-action buttons.
- Accent color: A striking Muted Red (#d9534f), reserved for critical alerts, error states, and prominent interactive elements that require immediate user attention.
- Background color: A clean and neutral Light Off-White (#f4f7f6), providing a soft, unobtrusive canvas for content and interactive components.
- Surface color: Pure White (#ffffff) for card backgrounds, modal dialogs, and other layered UI elements, offering a crisp distinction.
- Status indicators: Clear visual cues for system feedback using a vibrant Success Green (#5cb85c), an attention-grabbing Warning Yellow (#f0ad4e), and the critical Error Red (#d9534f).
- Font choice: 'Inter' (sans-serif), selected for its exceptional legibility and modern, objective aesthetic, making it ideal for both concise headings and data-dense body text in a professional context. Headings are set in uppercase and bold, often in stark white (#ffffff) for maximum impact against darker elements, while data elements use a precise 12px size in dark gray (#333333) to ensure clarity.
- Utilize a set of crisp, clear line icons that complement the professional and organized nature of the system, prioritizing easy recognition and intuitive understanding of functions.
- A dark-themed sidebar provides clear separation for primary navigation elements. A top-bar-horizontal layout handles global actions and branding. Dense data display grids optimize space, allowing users to view more information at a glance within tables and lists.
- Subtle and functional animations will provide seamless user feedback for interactions like data loading, form submissions, and state changes, ensuring a smooth and responsive experience without distraction.
